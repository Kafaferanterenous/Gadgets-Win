* Created the active E:\Codex_Work project as a selected copy of historical
  Gadgets v9. The historical E:\scripts source and known-good v9 artifacts
  were not modified.
* Added transition-only hover invalidation. Repeated WM_MOUSEMOVE messages no
  longer request a full repaint, and hover repainting no longer erases the
  background first.
* Added date-aware calendar refresh instead of repainting the calendar on every
  one-second timer tick.
* Added a compatible-memory-DC calendar paint path and publishes each finished
  calendar frame with one BitBlt operation.
* Removed the app's immediate-shutdown confirmation and delayed-shutdown
  information dialogs.
* Immediate Now speaks "Shutting down now" synchronously, then invokes the
  local Windows `shutdown.exe /p /f` no-timeout/no-warning path. `/f` can cause
  loss of unsaved work.
* Delayed shutdown uses `shutdown.exe /s /t <seconds>`. On a zero exit code,
  Delay changes to Cancel and the delay edit is hidden. Cancel invokes
  `shutdown.exe /a`, waits for a zero exit code, restores the controls, and
  speaks "Shutdown cancelled."
* Schedule, cancel, and command-failure voice paths use the installed Windows
  SAPI voice. Speech failure does not fabricate command success.
